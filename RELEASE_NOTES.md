# CreamyKeys v1.6.0

Full keyboard coverage, responsive device layout, and reusable sound profiles.

## Highlights

- Rebuilt the virtual keyboard on one logical coordinate system so function keys, navigation, arrows, numpad, and mouse scale together without overlapping.
- Added Esc, F1-F12, Print Screen, Scroll Lock, Pause, Insert, Delete, Home, End, Page Up/Down, full numpad, mute/volume controls, and a safe Power key with a shutdown-style sound.
- Centered the complete keyboard and mouse group from its measured rendered bounds at compact and large window sizes.
- Added Dashboard sound-source switching between **CreamyKeys Original** and a lightweight synthesized **VIA Tone**.
- Added custom sound profiles stored in `assets/profiles`; save, select, update, and delete profiles without rebuilding a preset.
- Profiles preserve keyboard/mouse packs, source, volumes, layers, boost, and natural variation.
- Aligned Trailer and User guide to the same fixed sidebar icon/text columns.
- Expanded smoke tests to cover VIA synthesis, Power sound, configuration migration, and profile save/load/delete.

## Download

Download `CreamyKeys-portable-v1.6.0.zip`, extract it, and run `CreamyKeys.exe`. A standalone executable and the product trailer are also attached for convenience.

Run as administrator when using CreamyKeys with elevated games.
