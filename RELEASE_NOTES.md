# CreamyKeys v1.0.0

Initial public desktop release.

## Highlights

- Keyboard and mouse ASMR sounds for normal Windows desktop apps and many games.
- Portable `CreamyKeys.exe` build.
- Virtual keyboard and mouse with live key/button highlights.
- Keyboard layout and mouse style selection.
- Sound presets, output volume, key boost, volume jitter, and pitch jitter.
- Per-key and per-button customization.
- App allow list and behavior controls.
- Tray menu for quick settings and admin/startup actions.

## Download

Download `CreamyKeys-portable.zip`, extract it, and run `CreamyKeys.exe`.

Run as administrator when using CreamyKeys with elevated games.
